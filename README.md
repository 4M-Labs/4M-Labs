## What We Build

### AI Agents & LLM Infrastructure
We design, build, and deploy autonomous AI agent systems -- from single-purpose tools to multi-agent orchestration pipelines. Our work spans LLM routing, agent evaluation, skill-based architectures, and verified reinforcement learning environments.

- **Agent orchestration** -- multi-agent systems with tool use, memory, and planning
- **LLM routing & optimization** -- cost-aware model selection and fallback chains
- **Verified Skill RL** -- turning public agent skills into trainable RL environments ([skill-gym](https://github.com/michielhdoteth/skill-gym))
- **Prompt engineering** -- chain-of-thought, ReAct, few-shot, and structured output patterns

### Software Development
Full-stack applications built with modern frameworks. TypeScript, Python, React, Next.js, FastAPI, PostgreSQL -- whatever the problem demands.

- **Web applications** -- SaaS dashboards, admin panels, client portals
- **APIs & backends** -- REST, GraphQL, WebSocket, real-time data pipelines
- **Mobile apps** -- React Native, Flutter, iOS/Android native

### MVP Development
From zero to launch in weeks. We help startups and teams ship their first version fast, then iterate based on real user feedback.
